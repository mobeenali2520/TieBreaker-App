## 💡 The Real-World Problem & Solution

### The Real-World Dilemma
Every day, professionals, founders, product leads, and individuals face high-stakes complex choices—such as evaluating job offers, choosing tech stacks, navigating real estate purchases, or selecting strategic investments. 

Standard decision-making suffers from three fatal flaws:
1. **Analysis Paralysis & Overthinking**: Too many conflicting variables with no quantitative framework to score them.
2. **Hidden Confirmation Bias**: People sub-consciously favor an option and ignore critical downside risks or blind spots.
3. **Flat, Static Comparisons**: Simple pros/cons lists treat a $100,000 salary bump equal to a 10-minute shorter commute without weighting criteria importance or testing long-term resilience.

### The Solution: The Tiebreaker
**The Tiebreaker** is an end-to-end, AI-powered decision intelligence suite that transforms messy, emotional dilemmas into structured, mathematically grounded, executive-grade decision frameworks. 

By combining **Multi-Criteria Decision Analysis (MCDA)**, **Game-Theoretic Stress Testing**, **SWOT Matrix Decomposition**, and **"What-If" Sensitivity Simulation**, *The Tiebreaker* eliminates hesitation and reveals the single optimal path with quantifiable confidence scores.

## 🧠 AI Integration & Prompt Engineering Architecture

The application is powered by **Google Gemini 3.6 Flash** (using the `@google/genai` TypeScript SDK) routed through an Express backend proxy. To ensure 100% uptime, the system incorporates an **AI Failover Service Manager** that automatically falls back to secondary models or local heuristic synthesis if rate limits are reached.

### AI Endpoints & System Prompts

#### 1. AI Context Clarification (`/api/ai-intake`)
**Purpose**: Formulates 3 dilemma-specific probing questions to extract constraints and risk profile.

```typescript
// System Prompt defined in server/ai/helpers.ts
export function buildIntakePrompt(dilemma: string, rawOptions?: string[]): string {
  return `You are a strategic decision consultant. A user is facing the following critical decision:
"${dilemma}"
${rawOptions && rawOptions.length > 0 ? `User mentioned these initial candidate choices: ${rawOptions.join(", ")}` : ""}

Formulate exactly 3 highly specific, probing clarifying questions to extract their underlying priorities, budget/constraints, and risk tolerance for evaluating this decision.

Return ONLY a valid JSON object matching this schema:
{
  "questions": [
    {
      "id": "q1",
      "question": "Clear, concise question statement",
      "contextNote": "Brief 1-sentence note on why this matters for criteria weighting",
      "placeholder": "Helpful input placeholder example",
      "options": ["Option Choice 1", "Option Choice 2", "Option Choice 3", "Option Choice 4"]
    }
  ]
}`;
}
```

## 🚀 How to Run the Project Locally

### Prerequisites
* **Node.js** (v18.0.0 or higher)
* **npm** or **bun**
* **Google Gemini API Key** ([Get your key on Google AI Studio](https://aistudio.google.com/))

### 1. Clone the Repository
```bash
git clone https://github.com/mobeenali2520/TieBreaker-App.git
cd TieBreaker-App
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Environment Variable Setup
Create a `.env` file in the root directory:

```env
GEMINI_API_KEY=your_google_gemini_api_key_here
PORT=3000
```

*(Note: See `.env.example` for reference).*

### 4. Run in Development Mode
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 5. Production Build & Execution
To build both the React client and Express backend into production bundles:

```bash
# Build Vite SPA & Bundle server.ts with esbuild
npm run build

# Start production Node server
npm start
```
